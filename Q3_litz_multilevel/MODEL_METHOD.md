# 模型、指标与验证方法

> 2026-09-27 续作说明：最终推荐、追加网格检查与误差边界见 `问题三_结果与控制变量.md` 和 `final_results.json`。下文独立验证的 5% 门槛是初始筛选门槛；后续三级候选超标的记录另存 `data/rom_post_confirmation.json`，不能将初始通过状态解释为所有候选均有 5% 精度保证。

## 1. 研究对象与几何含义

本研究使用传统递归绞合：单丝形成子束，子束再逐级绞合。分组参数从内到外列出，例如 4×4×4 表示 64 股、三级绞合；不是在一个截面上摆放三圈导线。

每一级子轴线在父轴线的法向平面内偏移：

`C_child(t) = C_parent(t) + r[cos(phi(t)) e1_parent(t) + sin(phi(t)) e2_parent(t)]`。

其中 `phi(t)=2πt/p+phi0`，带符号的 p 是相对于父束材料坐标的节距；t 表示整体轴向参数。各级轨迹叠加时法向平面随父束运动。实际绞角、丝长、局部弯曲及垂直总轴的截面位置从曲线求出，不能用几个互相独立的螺旋角替代。

各股圆截面始终垂直于自己的局部轴线。总铜面积 6 mm² 是各单丝法向面积之和，`d=√[4A/(πN)]`；切向倾斜会使全局横截面呈椭圆，这不表示铜丝直径变大。按照实际轴向长度计，铜体积和电阻随绞合增长率改变。

## 2. COMSOL 真三维周期场

每一根铜丝均建立独立三维实体，导线外为不导电区域。低频磁准静态近似下，联合求解磁矢势 A 和周期电势 φ：

`J = σ[-grad(phi) − iωA + (V0/L) ez]`，`div(J)=0`，`curl(curl(A)/μ)=J`。

采用磁场接口与电流接口的全耦合计算。每一条周期股线映射闭环设置一个电势参考点，仅去除电势常数，不是把各股在截面上重新短接。**没有给任意一股指定 I/N。**

短单元的上下端允许旋转和股线重编号。位置、切向、磁矢势及电势使用同一映射；单元长度通过映射验证，不能直接取最短节距。圆截面的扫掠方向仅决定 CAD 曲面如何表示，不是改变导线的物理截面。

采用静态形式的 Coulomb 规范 `div(A)=0`。COMSOL 磁场接口默认频域规范节点同时涉及电流守恒，直接与独立电流接口并用会造成重复约束，因此本实现显式选择静态规范形式。依据为本机 COMSOL 6.2 官方说明 `acdc_ug_theory.05.60.html`。

外部圆柱半径统一为 6 mm，边界采用磁绝缘；另用 10 mm 空气半径验证其对损耗的影响。结果描述长导线周期内部的每米等效参数，不包含实际接头和端部引线损耗。

## 3. 有效值、电阻与功率核对

COMSOL 使用峰值复相量。原始电流 `Iraw = integral_copper(Jz)/L`。归一化至 20 A RMS 后：

- 各股电流：`Ij,RMS = Ij,raw × 20 / Iraw`；
- 电流密度云图：`|J|RMS = |Jraw| × 20 / |Iraw|`；
- 交流电阻：`Rac = integral_copper(|Jraw|²/σ) / (|Iraw|² L)`；
- 铜损：`Pcu = 20² Rac`；
- 输入功率核对：`Rpower = Re(V0/Iraw)/L`，与损耗积分得到的 Rac 对比。

Rdc 使用 10 Hz 的三维极限解，并与逐股实际丝长的并联电阻核对。主指标为 Rac/Rdc，同时报告 Rac、Pcu、最大复电流偏差 `max|NIj/Itotal−1|`。后者同时反映幅值和相位，不与仅比较电流幅值的偏差混用。

## 4. Python 物理近似的含义与限制

Python 在真实递归轨迹的截面上更新导体位置及切向，计算圆导线的解析集肤阻抗和圆周多极场耦合；外部圆边界使用镜像项。根据局部切向和实际丝长修正导线方向及局部偶极耦合。再沿经验证的周期单元积分，联立求解各周期闭环的电流。

该方法保留股间电流不均及局部邻近损耗，但**局部截面模型不是完整的三维非局部磁场求解器**。它对弯曲导体互感的近似必须由独立 COMSOL 样本检查。没有使用经验节距惩罚项，也没有通过人为统一各股电流来制造均流结果。

第二版额外计算沿单丝轴向的磁场引起的圆周涡流。无限长圆导线在均匀轴向磁场中的解析响应为 `alpha_parallel = πa²[2J1(x)/(xJ0(x))−1]`，其中 `x=(1−i)a/δ`。单位长度、峰值磁场对应的损耗为 `0.5ωμ[−Im(alpha_parallel)]|H_parallel|²`。此系数由 Bessel 解确定，不含拟合量。对两个丝径、三个频率，将该公式与 `J_phi=−dH_z/dr` 的独立焦耳热积分比较，误差均在浮点精度水平。它只验证局部圆柱公式，不能代替整根绞线的三维验证。

第一版缺少该项的程序和预测均保留。发现问题时已经观察过的单级基准与正节距两级样本属于开发集；随后尚未得到 COMSOL 结果的两组三级样本及新增反向两级样本作为独立验证集。曲线导体远处自身磁场、轴向涡流之间的三维相互作用等仍属于局部近似的限制。

在选优之前保存独立样本的预测及源程序校验值。以 5% 为初始误差门槛，同时要求可分辨候选的优劣排序一致；未通过时参数搜索程序会拒绝启动。即使通过，这也只允许候选筛选，最后仍须以新的三维 COMSOL 模型确认结果。

## 5. 数值证据与解释边界

单根圆导线的三维试算与解析集肤解核对；3×3 小规模周期试算验证电流连续性、功率、网格、空气半径与计算长度。正式 6 mm² 基准另行完成相同类型检查后冻结，不能用小规模试算冒充正式基准。

几何距离检查包含相邻周期副本，并从分段直线最小距离中扣除样条曲率误差界。该结果约束的是 Python 样条曲线；CAD 几何与有限元网格仍需独立检查。失败、未完成及仅供诊断的算例保留在原始记录中，不参加设计优劣评价。

各结构统一材料、频率、电流、总铜面积、绝缘与边界。分组改变会同时影响径向移动、外径和空隙率，因此结构方案间的差异是综合效果；单因素节距和绞向组用于进一步解释，而不是将全部收益归因于某一个机制。

本次暂不计算温度反馈、介质损耗、分布电容、制造成本和疲劳寿命；题目中的电流密度约束按直流平均面积核对，不能据此声称已经完成真实温升仿真。
